## Latest post

**[Integrated Transcriptome-Metabolome Analysis of Rps2-A226Y Mutant Liver](https://iosinnii.github.io/blog-iosinnii/posts/rps2-a226y-liver-integrated-omics/)**

This post is part of my PhD project, carried out between 2020 and 2022. It compares liver transcriptomics and metabolomics from female Rps2-A226Y knock-in mice with wild-type controls, and tracks the pathway changes across two ages.
